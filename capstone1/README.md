#Capstone1
  본 프로젝트는 4학년 Capstone프로젝트를 구성하기 위한 기능적인 테스트를 진행한 예제 프로젝트이다.

## Get Starts
  본 프로젝트의 사용법은 flutter + andriod studio의 기본 사용법을 따른다.

  Flutter 기본 사용법
  
  - 'flutter clean', 'flutter pub get', 'flutter run' 명령어를 차례로 사용하여 어플리케이션 사용
  - 'flutter clean'로 리소서 초기화
  - 'flutter pub get'로 "projectname"/pubspec.yaml 파일내 리소스 적용
  - 'flutter run'로 코드 실행
  - lib/main.dart 코드에서 기능 구현 및 실행

  Flutter Icon 설정
  - '1024 x 1024' 이미지를 "projectname"/pubspec.yaml 파일 내 Icon 파일 경로로 저장
  - 'dart run flutter_launcher_icons' 명령어로 경로내 이미지 파일을 Icon으로 변환
  
  Flutter Splash설정
  - '1024 x 1024' 이미지를 "projectname"/pubspec.yaml 파일 내 Splash 파일 경로로 저장
  - 'dart run flutter_native_splash:create' 명령어로 경로내 이미지 파일을 Splash로 변환
