# Capstone1  
## Patient Medication Sync System - Prototype & Function Test

본 폴더는 대학교 4학년 졸업 Capstone 프로젝트의 최종 구현 이전 단계에서 기능 테스트 및 프로토타입 개발을 위해 제작된 프로젝트 폴더입니다.

`Capstone1`에서는 Flutter, Firebase, Web, IoT 디바이스 간의 연동 가능 여부와 핵심 기능 구현을 우선적으로 테스트하였으며, 이후 최종 프로젝트인 `Capstone2` 개발의 기반이 되는 구조를 설계하였습니다.

---

## 프로젝트 목적

- Firebase 기반 데이터 저장 및 동기화 테스트
- Flutter 애플리케이션 기능 구현 테스트
- 환자 및 복약 정보 관리 기능 검증
- 웹 기반 데이터 관리 기능 구현
- IoT 디바이스 연동 가능 여부 확인
- 최종 프로젝트 구조 설계 및 기능 검증

---

## 주요 테스트 기능

- 환자 및 병원 정보 등록
- Firebase Firestore 데이터 저장 및 조회
- 복약 시간 등록 및 조회
- Flutter 기반 UI 구성
- 복약 알림 기능 테스트
- 웹 페이지 데이터 관리 기능
- 약 복용 시 좋은 음식 / 나쁜 음식 정보 저장
- ESP8266 / ESP32 기반 IoT 디바이스 연동 테스트

---

## 사용 기술

- Flutter
- Firebase Authentication
- Cloud Firestore
- HTML / JavaScript
- ESP8266 / ESP32

---

## 프로젝트 특징

본 폴더는 기능 검증 및 테스트를 목적으로 제작된 프로토타입 프로젝트로, 일부 기능은 실험적 구조로 구현되어 있습니다.

이후 `Capstone2` 프로젝트에서 기능 개선 및 UI 통합 작업을 진행하여 최종 제출 형태의 스마트 복약 관리 시스템으로 발전시켰습니다.

---

## 관련 프로젝트

- `Capstone1`  
  기능 테스트 및 프로토타입 개발 프로젝트

- `Capstone2`  
  기능 구현 및 통합을 완료한 최종 제출용 프로젝트
