# Capstone Project  
## Patient Medication Sync System

본 프로젝트는 대학교 4학년 졸업 Capstone 프로젝트를 위한 기능 테스트 및 최소 구현 예제 프로젝트입니다.  
환자의 복약 정보를 효율적으로 관리하고, 병원 · 보호자 · 사용자 간의 데이터를 실시간으로 공유할 수 있는 스마트 복약 관리 시스템을 설계 및 구현하였습니다.

Flutter 기반 모바일 애플리케이션과 Firebase 서버를 중심으로 구성되며, 웹 페이지를 통한 환자 및 약 정보 관리 기능과 직접 제작 및 구현한 IoT 디바이스 연동 기능을 포함합니다.

## 주요 기능

- 환자 및 병원 정보 등록
- 복약 시간 저장 및 조회
- Firebase 기반 실시간 데이터 동기화
- 복약 알림 기능
- 약 복용 시 좋은 음식 / 나쁜 음식 정보 제공
- Flutter 기반 모바일 복약 관리 시스템
- 웹 기반 데이터 관리 페이지 제공
- ESP8266 / ESP32 기반 IoT 알림 디바이스 연동

## 사용 기술

- Flutter
- Firebase Authentication
- Cloud Firestore
- HTML / JavaScript
- ESP8266 / ESP32

## 프로젝트 목적

고령자 및 복약 관리가 필요한 사용자가 약 복용 시간을 보다 쉽게 관리할 수 있도록 지원하고, 복약 정보를 실시간으로 연동하여 사용자 편의성과 복약 안정성을 높이는 것을 목표로 합니다.

또한 모바일 애플리케이션, 웹 서비스, IoT 디바이스를 하나의 시스템으로 통합하여 실제 의료 및 헬스케어 환경에 적용 가능한 스마트 복약 관리 플랫폼 구현을 목표로 합니다.
