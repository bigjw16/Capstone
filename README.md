# Capstone Web Dashboard

병원 및 환자 관리용 웹 대시보드입니다.

## 프로젝트 소개

본 프로젝트는 캡스톤 디자인 과제로 개발 중인 복약 관리 시스템의 웹페이지 버전입니다.

의료진이 환자 정보를 등록하고 관리할 수 있으며, 환자의 복약 정보 및 관련 데이터를 확인할 수 있도록 구성되어 있습니다.

## 주요 기능

* 환자 정보 등록
* 환자 정보 수정
* 약물 정보 관리
* 복약 스케줄 확인
* 병원 전용 관리 페이지
* Firebase 기반 데이터 연동

## 프로젝트 구조

```text
Capstone/
│
├── hospital.html          # 병원 관리 웹페이지
├── 웹페이지 들어가기.txt    # 접속 방법 안내
└── README.md
```

## 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/bigjw16/Capstone.git
```

### 2. 브랜치 이동

```bash
git checkout webpage
```

### 3. 웹페이지 실행

`hospital.html` 파일을 브라우저에서 실행합니다.

또는 VS Code의 Live Server를 이용하여 실행할 수 있습니다.

## 개발 목적

고령자 및 환자의 복약 순응도를 향상시키기 위한 스마트 복약 관리 시스템 구축을 목표로 합니다.

모바일 앱, Firebase 데이터베이스, IoT 디바이스(ESP8266/ESP32) 및 웹 대시보드를 연동하여 통합 복약 관리 환경을 제공합니다.

## 향후 개발 예정

* 실시간 복약 현황 모니터링
* 복약 통계 시각화
* 의료진 전용 대시보드
* 보호자 연동 기능
* 알림 및 로그 관리 기능
